# Деплой сайта на хостинг (cPanel/FTP)

Сайт статический — просто файлы, никакой сборки не нужно. Заливаете
как есть.

## Что заливать

Из корня проекта — **всё, кроме** служебных папок:

```
index.html
robots.txt
css/
js/
images/
```

**НЕ заливайте**: `.git/`, `.claude/`, `worker/`, `.gitignore`,
`SETUP-TELEGRAM.md`, `DEPLOY.md` — это внутренние файлы проекта и
серверная часть бота, сайту они не нужны.

## Через File Manager (в панели хостинга)

1. Зайдите в cPanel → **File Manager**.
2. Откройте папку `public_html` (или `www` — там, где должен лежать
   сайт для домена qafqazavto.az). Если домен привязан к
   поддиректории — зайдите в неё.
3. Загрузите (Upload) файлы и папки из списка выше — сохраняя структуру
   (то есть `css/style.css` должен лежать именно в `public_html/css/style.css`,
   а не в корне).
4. Откройте qafqazavto.az в браузере — должна открыться главная страница.

## Через FileZilla (FTP-клиент)

1. Данные для подключения — в панели хостинга (обычно раздел
   «FTP-аккаунты») или в письме от регистратора: **хост**, **логин**,
   **пароль**, порт обычно 21.
2. В FileZilla: Файл → Менеджер сайтов → новый сайт, вставьте хост/
   логин/пароль → Подключиться.
3. Слева — ваш компьютер, справа — сервер. Зайдите справа в
   `public_html` (или нужную папку).
4. Перетащите файлы/папки из списка выше слева направо.
5. Дождитесь завершения передачи (внизу — очередь) → проверьте сайт
   в браузере.

## После каждого обновления сайта

Просто повторите заливку изменившихся файлов (FileZilla подсветит,
какие новее локально). Кэш браузера может показывать старую версию —
обновите страницу с Ctrl+F5, если не видите изменений.

## Форма заявки

Форма отправляет данные напрямую на Cloudflare Worker
(`qafqaz-avto-booking.elmin95-az.workers.dev`), а не на ваш хостинг —
заливка сайта на хостинг никак не затрагивает эту часть, она уже
работает независимо (см. `SETUP-TELEGRAM.md`).
